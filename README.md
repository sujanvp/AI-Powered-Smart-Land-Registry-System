# AI-Powered Smart Land Registry System

## Overview
The AI-Powered Smart Land Registry System is a web application
designed to support land registration, document verification,
ownership tracking, and property transfer management using
AI and machine learning technologies.

## Key Features
- Land Registration Management
- Land Transfer Requests and Approvals
- Transfer Approval Certificate
- Final Transfer Certificate
- Revenue Officer Registration and Admin Approval
- OCR-Based Document Verification
- AI-Based Fraud Detection
- Property Price Prediction
- Survey Number-Based Search
- Ownership and Transfer History
- Notifications
- Admin Reports

## Objectives
- Improve land registration efficiency.
- Support document verification.
- Identify potentially suspicious registration details.
- Improve transparency in ownership and transfer history.
- Provide estimated property prices using machine learning.

## System Modules
1. User Authentication
2. Land Registration
3. Land Transfer Management
4. Document Verification
5. AI Fraud Detection
6. Property Price Prediction
7. Ownership History
8. Revenue Officer Management
9. Notifications and Admin Reports
